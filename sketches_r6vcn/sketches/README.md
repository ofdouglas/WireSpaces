# Mapping outputs

Place completed sketch files here.

## Collision rules (required)

1. **List this directory** before creating a file.
2. If the name you want **already exists**, choose a different `<agent_id>` suffix — **do not overwrite**.
3. Only revise an existing file when the orchestrator **explicitly** assigns that path to you.

Tool names (`cursor`, `claude`, `agent`) are not unique across runs. Use an orchestrator-assigned id: `agent_a`, `mapper_2`, `run3`, etc.

## Naming

```text
<archetype_id>_<short_name>_<agent_id>.md
```

Examples:

```text
07_peer_can_dense_agent_a.md
07_peer_can_dense_agent_b.md
04_multi_can_gateway_mapper_1.md
```

Record the actual path in the sketch header:

```text
**Output file:** sketches/07_peer_can_dense_agent_b.md
```

Use [`../template_sketch_output.md`](../template_sketch_output.md) as the section skeleton.
